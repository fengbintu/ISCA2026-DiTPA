## Documention for `config/`

This directory contains configuration files for DiTPA evaluations.

- `config_diffusion_openx.yaml`: including model configuations, checkpoint path, dataset name for software evaluation
- `dataset/openx.yaml`: including dataset path and trajectory related configurations for software evaluation
- `model/action_planner.yaml`: including action planner structure and input configurations for software evaluation
- `action_planner_structure.xlsx`: including the action planner layer information for hardware evaluation
